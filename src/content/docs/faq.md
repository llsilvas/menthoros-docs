## Treinador — FAQ e solução de problemas

| Situação | O que fazer |
| --- | --- |
| **Convite inválido ou expirado** no cadastro | Peça um novo convite. Treinador sem convite: **Entrar na lista de espera**. |
| Atleta não recebeu o convite | Confira o e-mail no cadastro do atleta e use **Enviar convite** de novo. |
| **Já existe um plano ativo** ao gerar | Encerre a semana do atleta ou rejeite o plano atual antes de gerar outro. |
| Atleta não vê o plano | O plano só aparece depois de aprovado em **Revisão de planos**. |
| Treino com **Erro no envio** ou **Não conectado** | O atleta precisa conectar (ou reconectar) o intervals.icu em **Perfil › Conexões**. |
| Treino feito não apareceu | Aguarde a sincronização ou registre em **Registrar treino** (.fit ou manual, até 7 dias). |
| **Melhores esforços** vazio | Exige conexão com o intervals.icu. |
| Gráfico de forma sem dados | Os indicadores aparecem a partir do primeiro treino sincronizado. Comparações exigem 4 semanas. |
| **O plano mudou em outra sessão** | Recarregue a página para ver o estado atual antes de editar. |
| Projeção de prova não aparece para o atleta | Clique em **Marcar como Oficial** no resultado da projeção. |
| Trocar nome ou logo da assessoria | **Configurações › Configurar assessoria**. |
| Mudar plano ou limites da assinatura | Fale com o suporte. |
| Excluir a conta | **Configurações › Solicitar exclusão de conta**; a exclusão é confirmada por e-mail. |

## Atleta — Dúvidas frequentes

| Situação | O que fazer |
| --- | --- |
| **Convite inválido ou expirado** ao criar a conta | Peça um novo convite ao seu treinador. |
| Não recebi o e-mail de convite | Peça ao treinador para conferir seu e-mail no cadastro e enviar o convite de novo. |
| Não vejo o plano da semana | O plano só aparece depois que o treinador aprova. Aguarde a aprovação. |
| O treino não chegou ao relógio | Conecte (ou reconecte) o intervals.icu em **Perfil › Conexões**. |
| Treino feito não apareceu | Aguarde a sincronização ou use **Registrar treino** (.fit ou manual, até 7 dias). |
| Melhores tempos vazios | Exige conexão com o intervals.icu. |
| Gráfico de forma sem dados | Os indicadores aparecem a partir do primeiro treino sincronizado. Comparações exigem 4 semanas. |
| Não vejo a projeção da minha prova | Ela só aparece depois que o treinador a marca como oficial. |
